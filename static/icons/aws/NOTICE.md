# Iconos de AWS

Los archivos SVG de esta carpeta provienen del paquete oficial **AWS Architecture Icons**
(https://aws.amazon.com/architecture/icons/, versión del 31 de julio de 2026) y son propiedad de Amazon Web Services.
AWS permite usarlos para crear diagramas de arquitectura. **No están cubiertos por la licencia MIT** del resto del
repositorio. Para actualizarlos: `python3 app.py --setup-icons`.
